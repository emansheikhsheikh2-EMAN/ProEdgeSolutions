# Day 4 - Student Utility Toolkit

## Objective
A modular Python application demonstrating functions, modules, variable scope, and lambda functions.

## Features
- Add Student Information
- Display Student Information
- Update Student Information
- Calculate Total, Average and Percentage
- Calculate Student Grade
- Find Highest and Lowest Marks
- Sort Student Marks
- Search Student Records
- Lambda Functions
- Local and Global Scope Demonstration
- Interactive Menu System

## Modules
- `student_info.py` - Student information management
- `academic.py` - Academic calculations and scope demonstration
- `utility.py` - Marks utilities and lambda functions
- `main.py` - Main menu and program execution

## Technologies
- Python
- Functions
- Modules
- Lambda Functions
- Variable Scope
