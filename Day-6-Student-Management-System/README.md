# Day 6 - Student Management System

## Project Overview
A command-line Student Management System developed using Python. The application allows users to manage student records and academic information using JSON file storage.

## Features

### Student Management
- Add New Student
- View All Students
- Search Student by ID
- Update Student Information
- Delete Student Record

### Academic Management
- Enter Student Marks
- Calculate Total Marks
- Calculate Percentage
- Generate Grade
- Display Academic Status

## Technical Concepts Used
- Python Fundamentals
- Conditional Statements
- Loops
- Functions
- File Handling
- JSON Data Storage
- Exception Handling
- Input Validation

## File Structure

- `student_management.py` - Main Python application
- `students.json` - Stores student records permanently
- `day_6_menu.png` - Main menu screenshot
- `day_6_academic_result.png` - Academic result screenshot

## Sample Result

The system calculates total marks, percentage, grade, and academic status automatically.
