# Day 11 – SQL Fundamentals & Database Analysis

## Objective

Learn SQL fundamentals and perform database analysis using SQLite. Practice creating tables, inserting data, filtering, sorting, aggregation, joins, subqueries, window functions, and CTEs.

## Technologies Used

- SQL
- SQLite
- VS Code

## Database

Database File: `student_database.db`

Main Tables:
- Students
- Departments
- Courses

## SQL Concepts Covered

### Basic SQL
- SELECT
- WHERE
- ORDER BY
- COUNT()
- AVG()
- MAX()
- MIN()

### Grouping & Analysis
- GROUP BY
- HAVING
- Department-wise analysis

### Joins
- INNER JOIN
- LEFT JOIN

### Advanced SQL
- Subqueries
- ROW_NUMBER()
- RANK()
- Common Table Expressions (CTEs)

## Project Highlights

- Filtered students based on marks
- Sorted students from highest to lowest marks
- Calculated total and average marks
- Found highest and lowest marks
- Performed department-wise analysis
- Joined students with department information
- Identified students scoring above the class average
- Ranked students using SQL window functions
- Used CTEs for advanced analysis
